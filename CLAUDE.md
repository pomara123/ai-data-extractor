# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Running the app

```bash
source venv/bin/activate
streamlit run app.py
```

Requires `OPENAI_API_KEY` in `.env` (loaded automatically via `python-dotenv`).

The `output/` directory must exist before saving metadata — create it if missing: `mkdir -p output`.

## Architecture

This is a Streamlit app that extracts structured metadata from scientific data files using a combination of deterministic parsing and an OpenAI LLM call.

**Data flow in `app.py`:**
1. `file_parser.extract_text(uploaded_file)` → returns a plain string (file content / FCS header summary)
2. `metadata_extractor.extract_metadata(text, vocab)` → calls OpenAI, returns a dict matching `Metadata` fields
3. UI renders every field from `Metadata.model_fields` as an editable input
4. Save writes to `output/extracted_metadata.json`

**FCS text extraction** (`fcs_parser.py`):
- `fcs_metadata_to_text` flattens FCS header fields (`$CYT`, `$TOT`, `$PAR`, `$PnN`, `$PnS`) into a plain-text summary that the LLM uses to infer all metadata fields including instrument, markers, and modality.

**Controlled vocabulary** lives in `vocab/controlled_vocab.yaml`. It is loaded in `app.py` and injected into the prompt via `utils/prompt_builder.build_prompt`. All LLM-extracted fields must use terms from this file.

**`models/metadata_models.py`** is the source of truth for what fields exist. The UI form is generated by iterating `Metadata.model_fields`, so adding a field to the model automatically adds it to the UI.
